# Audit notes (13 Oct 2026)

## Fixed in this ZIP
- Companion server: static file serving is now an allowlist. Before, the server's .env, its source,
  the SQL files and other private files could be downloaded by anyone (tested).
- Companion server: loads its own .env file. Before, the README steps left VATAR_SECRET empty
  because Node does not read .env files by itself.

- app.js: when the Lagos Life SDK fails to load or Vatar.init() is refused, the lobby now shows the real
  reason (for example "not_framed") with a Retry button instead of "Connecting..." forever.
- sw.js: the service worker no longer touches requests to lagoslife.app (the docs say never use a copy of the SDK).

- app.js: terms for Publish / Join / Quick match are now an in-page screen (window.confirm is blocked in the Lagos Life frame).
- Added render.yaml, DEPLOY-RENDER.md and server/test-server.mjs (run: node server/test-server.mjs).

## Still open (not fixed yet)
1. Outside the Lagos Life frame the lobby now shows a clear message; still untested in a real browser.
2. The new terms screen is untested in a real browser.
3. Challenge list, moves and match config are in server memory (lost on restart, single instance only).
4. Solve-Off "solved" and Cell Capture moves are trusted from the browser; no signed result is ever posted.
5. Join-by-code modal and duplicate mode/time controls remain in index.html.
6. Sign-in/Friends/avatar upload may conflict with Lagos Life's "no logins or personal data" review rule.
7. Splash 8-second timer hides the splash but shows no error.
